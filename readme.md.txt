====================================================================
대한민국 천만 관객 영화 흥행 분석 대시보드
====================================================================

1. 프로젝트 개요
위키백과의 '대한민국의 영화 흥행 기록' 페이지에서 한국 작품 흥행 순위 데이터를 
수집하여 천만 관객 돌파 영화를 필터링하고, 주요 지표와 표, 차트로 시각화하는 
Streamlit 웹 애플리케이션입니다.

2. 주요 기능
- 웹 스크래핑: requests와 BeautifulSoup을 이용해 위키백과 표 데이터 추출
- 데이터 정제: 제목 괄호 제거, 관객수 정수 변환, 개봉 연도 및 월 추출
- 데이터 시각화: 
  * 천만 영화 수, 역대 1위 작품, 1위 관객 수 지표(Metric) 표시
  * 천만 관객 영화 전체 목록 표 출력
  * 관객 수 상위 10편 가로 막대차트
  * 개봉 연도별 천만 영화 편수 막대차트

3. 설치 방법
터미널(또는 명령 프롬프트)을 열고 프로젝트 폴더로 이동한 뒤 아래 명령어를 입력하여 
필요한 라이브러리를 설치합니다.

pip install -r requirements.txt

4. 실행 방법
설치가 완료되면 터미널에 아래 명령어를 입력하여 앱을 실행합니다.
(파이썬 파일 이름이 app.py라고 가정합니다)

streamlit run app.py

5. 파일 구성
- app.py : 메인 실행 파이썬 코드
- requirements.txt : 필수 설치 패키지 목록
- README.txt : 프로젝트 안내 문서
